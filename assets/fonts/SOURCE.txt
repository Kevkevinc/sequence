Committed rather than taken from the operating system on purpose. Rendered text
must look identical on every machine, and the production host has no font
directory at all: `lib/render/text.ts` loads this file by path with
`GlobalFonts.registerFromPath` and fails loudly if it is missing, so there is no
route to a silent fallback to whatever serif the platform happens to default to.

Set RENDER_FONT_PATH to point the renderer at a different TTF.
